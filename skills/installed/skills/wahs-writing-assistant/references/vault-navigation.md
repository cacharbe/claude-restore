## Key Navigation Rules

**Chapter order**: Always check `With All Her Senses/With All Her Senses/Index.md`
before referencing chapters by position. The Longform plugin manages order there.
Do not infer chapter order from file names alone.

**Lore before invention**: If a character, location, organization, or magical concept
exists in the Lore/ directory, read the file before writing about it. Do not reconstruct
from memory when the file is available.

**Planning notes**: Dated files in `Planning/` contain session decisions and story
arc thinking. Check these when working on plot structure -- they often contain Chuck's
most current thinking on where the story is going.

**Vignettes**: The `Vignettes/` directory holds finished or near-finished scenes that
haven't been placed in the main narrative yet. In Brainstorm mode, these are useful
reference points for tone and what's been written but not yet connected.
